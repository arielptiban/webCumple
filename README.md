# Una web para ti ♡

Proyecto Astro de una sola página (sin componentes ni dependencias de UI).

## Ejecutar

```bash
npm install
npm run dev
```

Abre la dirección que muestra Astro en el navegador y activa el modo móvil (ancho de referencia: 390 px).

## Personalizar

- Edita los textos, fecha, momentos y motivos en `src/pages/index.astro`.
- Pon tus imágenes en `public/fotos/` con los nombres `portada.jpg`, `hero.jpg`, `recuerdo-1.jpg`, `recuerdo-2.jpg`, `recuerdo-3.jpg`, `historia-1.jpg`, `historia-2.jpg`, `historia-3.jpg` y `final.jpg`.
- Pon la canción (con permiso de uso) en `public/audio/cancion.mp3`.
- El sitio muestra fotografías de relleno visual cuando esos archivos no existen. Puedes dejar las imágenes originales deshabilitadas hasta añadir los archivos.

La música comienza al pulsar "Abrir sorpresa", debido a las reglas de reproducción automática de los navegadores móviles.
